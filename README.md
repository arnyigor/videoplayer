# Anwap Movies

Android-приложение для просмотра фильмов и сериалов с поддержкой мобильных устройств и Android TV.

Приложение загружает каталог, данные страниц, ссылки на видео, сезоны, серии и комментарии с сайта Anwap, сохраняет историю просмотра, избранное и позволяет продолжать просмотр с последней позиции.

> Проект находится в активной разработке.

[Скачать APK](https://github.com/arnyigor/videoplayer/releases) • [Архитектура](Arch.md)

## Возможности

- Каталог фильмов и сериалов.
- Поиск и расширенная фильтрация.
- Экран деталей с описанием, рейтингами, жанрами, актёрами и режиссёрами.
- Просмотр комментариев с отдельным экраном, pull-to-refresh и загрузкой следующих страниц.
- Воспроизведение фильмов и серий через ExoPlayer.
- Выбор доступного источника видео.
- История просмотра и продолжение с последней позиции.
- Избранное.
- Кеширование видео для просмотра без повторной загрузки.
- Загрузка доступных видеофайлов.
- Поддержка Android TV-интерфейса.
- Picture-in-Picture для плеера.
- Управление яркостью, громкостью, перемоткой и размером видео жестами.

## Поддерживаемые источники

Приложение работает со страницами фильмов и сериалов Anwap:

- страницы фильмов;
- страницы сериалов;
- сезоны и серии;
- HLS/DASH/MP4-ссылки, если они доступны на странице;
- комментарии к фильму или сериалу.

Фактическая поддержка конкретного видео зависит от доступных ссылок, устройства, версии Android и возможностей декодера.

## Ограничения

- Приложение не является официальным клиентом Anwap.
- Доступность фильмов, сериалов, ссылок и комментариев зависит от сайта-источника.
- Некоторые ссылки могут перестать работать или требовать обновления данных.
- DRM-защищённые потоки не поддерживаются.
- Поддержка отдельных кодеков зависит от устройства.

## Конфиденциальность

- Приложение не требует аккаунт внутри приложения.
- История просмотра, избранное и кеш хранятся локально на устройстве.
- Для отправки комментария используется переход на сайт Anwap, где может потребоваться авторизация.
- Для сетевого воспроизведения и обновления каталога требуется доступ к интернету.

## Технологии

| Область | Технология |
|---------|-----------|
| Язык | Kotlin 2.0.21, Java 17 |
| DI | Koin 3.5.6 |
| База данных | Room 2.6.1 + Paging 3 |
| Сеть | Ktor 2.2.2, Jsoup 1.15.3 |
| Плеер | ExoPlayer 2.19.1 |
| Навигация | Navigation Component + SafeArgs |
| Изображения | Glide 4.16.0 |
| TV UI | Leanback 1.0.0 |
| Обработка видео | FFmpeg Kit |

## Архитектура

Проект использует единый модуль `app` и разделение по слоям:

| Пакет | Назначение |
|-------|-----------|
| `presentation/` | UI: Activities, Fragments, ViewModels, Services |
| `domain/` | Бизнес-логика: Interactors, Repository interfaces, Models |
| `data/` | Реализации: Room DB, Jsoup, Ktor, Prefs |
| `di/` | Koin-модули |

Подробнее: [Arch.md](Arch.md)
