```bash
./gradlew :app:assembleDebug --offline
./gradlew :app:testDebugUnitTest --offline
```

| Проверка | Результат |
|---|---|
| `:app:assembleDebug` | BUILD SUCCESSFUL |

| `connectedDebugAndroidTest` | не запускается: instrumentation-тестов в проекте нет (`app/src/androidTest` пуст) |
