# S-011 / F-019: попытка проверить двойной тап на живом экране (CPU-эмулятор)

Эмулятор поднят: `Pixel_5_API_30_ARM_Compat`, `-gpu swiftshader` (программная графика на CPU),
`sys.boot_completed=1`.

## Что сделано

1. Приложение установлено (`perfdebug`, Media3), фикстуры загружены, `adb reverse 8765` активен.
2. Сценарий: Фильмы → карточка → «Смотреть» → двойной тап по правой части экрана двумя
   командами `adb shell input tap`.
3. Позиция снималась из `dumpsys media_session` до и после.

Результат (`build/perf/c70-live/adb-doubletap.json`): позиция выросла ровно на время
воспроизведения (3127 → 6127 мс за 2 с), перемотки нет.

## Почему это НЕ доказывает дефект

Измерено (`build/perf/c70-live/tap-timing.json`): на этом эмуляторе **один** вызов
`input tap` занимает ~542 мс, а пауза между двумя отдельными вызовами — ~610 мс.
Окно двойного тапа в библиотеке — сотни миллисекунд, то есть два независимых `adb input tap`
физически не могут сложиться в двойной тап. Метод невалиден, а не жест сломан.

## Что ещё пробовал

- Инструментальный тест на живом экране (Espresso: История → «Продолжить просмотр» → синтетический
  двойной тап на настоящем `DoubleTapPlayerView`). Упирается в две вещи: (а) instrumentation
  прогон удаляет приложение вместе с его БД, поэтому история пуста и нажимать нечего;
  (б) системный диалог разрешений на свежих данных перекрывает активность.
  Тест удалён, чтобы не держать красный прогон.

## Что подтверждено вместо этого

`Media3GesturesTest` (2/2): та же `DoubleTapPlayerView` из Media3-форка на Media3-плеере
перематывает +10 с и −10 с. То есть механика жеста на Media3 работает.

## Вывод

Жест на живом экране остаётся **непроверенным**. Нужна одна из двух вещей:
- ручная проверка на устройстве/эмуляторе (двойной тап пальцем/мышью), или
- инструментальный тест с предварительно засеянной БД внутри прогона (push готовой БД через
  root-shell в `uiAutomation`), чтобы история/каталог не были пустыми.

До этого F-019 остаётся открытым; утверждать, что YouTube-жест работает после миграции,
нельзя.
