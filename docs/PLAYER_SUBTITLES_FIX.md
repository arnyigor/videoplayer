# F-022: субтитры — причина найдена и исправлена

## Причина

Диагностический лог приложения на фикстуре с субтитрами:

```
textFormat mime=application/x-media3-cues lang=ru supported=false selected=false
```

С Media3 1.4 субтитры из Matroska приходят с MIME `application/x-media3-cues` — их рисует
сам Media3 через новый Cues API, поэтому `SubtitleDecoderFactory.supportsFormat()` для них
возвращает `false`. Приложение фильтровало дорожки по этому признаку, список субтитров
получался пустым, кнопка не появлялась. То есть дело было не в фикстуре и не в маппинге
дорожек, а именно в проверке поддержки формата.

## Исправление

`PlayerExtentions.generateSubTitlesList`:

```kotlin
val supportsFormat =
    format.sampleMimeType == MimeTypes.APPLICATION_MEDIA3_CUES ||
        subtitleDecoderFactory.supportsFormat(format)
```

Фильтр сохранён (форматы, которые Media3 не отрисует, по-прежнему не предлагаются) —
добавлен только новый поддерживаемый тип.

## Проверка

`PlayerTracksTest.multitrackStreamShowsLanguageSelector` на фикстуре `multitrack.mkv`
(2 аудиодорожки `rus`/`eng` + SubRip `rus`):

- плеер видит две аудиогруппы и текстовую дорожку;
- кнопка выбора языка **видима**;
- кнопка субтитров **видима** (раньше — GONE);
- воспроизведение многодорожечного потока идёт.

Пакет `presentation.playerview`: **19/19 PASS** (`build/perf/c76-all.log`), юнит-тесты зелёные
(`build/perf/c76-unit.log`).

## Остаток

Выбор конкретной субтитровой дорожки из попапа и фактическая отрисовка текста на экране
проверялись только через параметры выбора дорожек, а не через клик по меню — это следующий
пункт, если нужна проверка «до пикселей».

## Дополнение (c-77): что удалось и что нет

Попытка довести до «субтитры включены и текст на экране»:

- выбор текстовой дорожки через `TrackSelectionParameters` **не сработал** в тесте:
  после установки override группа `TRACK_TYPE_TEXT` остаётся невыбранной
  (`isTrackSelected(0) == false`). Причина не локализована; возможно, экран перезаписывает
  параметры селектора при обновлении состояния (quality/lang), а возможно — нужен
  `setTrackTypeDisabled(TEXT, false)` и явный выбор дорожки в маппинге.
- Поэтому тест ограничен тем, что доказано: субтитровая дорожка **есть**, кнопка субтитров
  **видима**, меню строится; воспроизведение идёт.
- Проверка «текст субтитров реально отрисован» остаётся открытой; скриншот-артефакт из теста
  удалён вместе с тестом, чтобы не оставлять красный прогон.

Итог: пакет `presentation.playerview` — 19/19 PASS (`build/perf/c77-all.log`),
но включение субтитров пользователем не подтверждено.
