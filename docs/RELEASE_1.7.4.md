## Жесты в плеере (1.7.2 → 1.7.4)

Вертикальный свайп в полноэкранном плеере: правая половина — громкость и усиление,
левая — яркость. Вверх прибавить, вниз убавить; полный диапазон — 70 % высоты экрана.

Исправления после первой версии жестов:

- значения применяются прямо в `ACTION_MOVE`: раньше громкость ждала асинхронный
  `ContentObserver`, поэтому индикатор менялся только на отпускании пальца;
- убран троттлинг 50 мс, из-за которого быстрый свайп «перескакивал» значения;
- индикатор больше не перезапускает анимацию появления на каждом событии и не гаснет
  в середине жеста (`withEndAction(null)` + `cancel()`), поэтому он не мигает;
- после максимума системной громкости свайп вверх даёт **усиление** (`LoudnessEnhancer`),
  вниз — сначала снимает усиление, потом громкость;
- предел усиления берётся из настройки «Усиление звука» (значение в миллибелах: 1000 = +10 дБ);
- жест засчитывается как вертикальный только при заметном преобладании вертикали,
  вызывается `cancelInDoubleTapMode()`, одиночный тап ничего не меняет.

Покрыто `PlayerSwipeGestureTest` (5 тестов): рост/падение громкости справа, яркость слева,
обновление значений и индикатора **до** отпускания пальца, фактическое усиление
через `LoudnessEnhancer`, отсутствие изменений при одиночном тапе и сохранение
`isDoubleTapEnabled`.

читает карточку даже когда подпись обрезана вьюпортом.

## Исправлено ранее (1.7.1)

**Обновление карточки при 404 больше не вешает сервис.** Раньше страница ошибки разбиралась как фильм
с названием «Ошибка 404»: поток не присылал терминального события, foreground-сервис не останавливался,
уведомление висело без названия, а в деталях бесконечно крутился индикатор «Обновление данных…».
Теперь:

- 404 завершает разбор сразу (`complete=true, success=false`), без разбора страницы ошибки;
- уведомление содержит название карточки и текст «Сохранённые ссылки остаются доступны»;
- добавлен таймаут разбора (120 с) и страховка: если поток не прислал терминальное событие, операция всё равно закрывается;
- сохранённые ссылки и локальные данные при 404 не меняются — фильм продолжает воспроизводиться;
- мобильные и TV-детали дублируют итог тостом, потому что уведомление исчезает вместе с сервисом;
- регрессионный тест `Update404FlowTest`: локальный 404-сервер, проверка терминального события и отсутствия мусорного заголовка.

## Что вошло

- **Android TV**: постоянное меню из семи разделов, каталог фильмов/сериалов, история и избранное,
  настройки с управлением каталогом, единый поиск, плеер с дорожками, автоплеем и обработкой ошибок,
  входящие ссылки, сохранение состояния разделов.
- **Постеры** на всех экранах мобильной и TV-версии через один загрузчик с повторной попыткой по зеркалу.
- **Каталог**: атомарный импорт, предвалидация архива, отмена, прогресс и честный статус, миграции 3→8.
- **Поиск**: сохранение запроса/фильтров/результатов при переходе в детали и смене разделов,
  подписанный рейтинг в выдаче («IMDb 7,7» для каталога, «Рейтинг 7,7» для сайта).
- **Мобильный плеер**: независимые выборы аудио/качества, пауза при потере аудиофокуса вне PiP-исключения,
  убраны нерабочие субтитры.
- **Скачивание**: честный результат сохранения, тип сервиса `dataSync`, отмена при уничтожении.
- **Тема**: единый акцент `#B6A0FF` на мобиле и TV, читаемые выпадающие списки, сиреневые радиокнопки в диалогах.
