# Релиз 1.7.5

Версия: **1.7.5** (`versionCode 1705`). Изменения в `version.properties`; подпись берётся из локального
`signing.properties`, публикация — GitHub-workflow по тегу `v1.7.5`.

## Что вошло

### Сеть и подключение

- Ethernet больше не считается «нет сети»: добавлен `ConnectionType.ETHERNET`, проверяется
  `NET_CAPABILITY_INTERNET`. Загрузка, кэширование и автообновление базы разрешены на Ethernet,
  как на Wi‑Fi.
- VPN учитывается по тарификации (`NET_CAPABILITY_NOT_METERED`): тарифицируемый VPN требует
  подтверждения, а не разрешает фоновые операции молча.
- Отдельный статус «сеть подключена, но доступа в интернет нет» (`NET_CAPABILITY_VALIDATED`) —
  captive portal и мёртвый роутер больше не выглядят как отсутствие сети.
- Убран TV-обход «разрешать автообновление всегда»: политика одна для всех устройств.

### Качество видео

- Мобильное меню качества: пункт «Авто», подписи `1080p (1920 × 1080)`, сортировка по высоте,
  корректная отметка выбранного пункта. Кнопка качества видна и при единственном разрешении.
- TV: список качества пересобирается в `onTracksChanged` (DASH/HLS публикует рендишны позже
  `STATE_READY`), устаревший `TrackSelectionOverride` не применяется к новой серии.
- Проверено измерением: каталог сайта отдаёт потоки ~720×304…720×400, то есть выше 480p
  у источника нет — ограничение источника, а не плеера.

### Внешний плеер (телефон/планшет)

- Кнопка в плеере и пункт «Открыть во внешнем плеере» в меню карточки, системный chooser,
  сохранение позиции и пауза перед переходом; возврат не запускает воспроизведение сам.
- MIME подбирается с запасным `video/*` (иначе HLS ложно считался невоспроизводимым).
- Источники, требующие `Referer` (`interkh.com`, `ortified.ws`), внешнему плееру не предлагаются —
  правило вынесено в один модуль с внутренним плеером.

### Поиск и фильтры

- Мульти-выбор жанров: быстрые чипы в шторке + полный список чекбоксами на телефоне и на TV.
  Несколько жанров объединяются по ИЛИ.
- При активных фильтрах поиск идёт только по каталогу (сайт не умеет фильтровать жанры): список
  становится пустым с честной подсказкой вместо «ничего не изменилось». Сайтовая пагинация при
  фильтрах не подмешивается.
- Жанры в карточке делятся на отдельные чипы, даже если сайт прислал их одной строкой без запятых
  (`GenreSplitter` по словарю `R.array.genres`).
- «Назад» в поиске на главной: первое нажатие очищает текст и результаты, второе закрывает поиск.
- «Назад» с любой вкладки возвращает на главную (главная — корень), двойное нажатие для выхода
  работает только на главной.

### Исправления интерфейса

- Пустое избранное: кнопка «Найти фильм или сериал» больше не перекрыта RecyclerView и работает.
- Диалоги: единая тёмная alert-тема (`AppAlertDialogTheme`), светлый текст на тёмном фоне в любом
  системном режиме; убран сценарий «тёмный текст на тёмном фоне».
- Шторка фильтров: плавающая подпись поля светлая (была тёмной на тёмном).
- Иконка поиска и настроек в шапке главной не пропадает после закрытия поиска.
- «Сбросить» в шторке фильтров снимает и быстрые чипы жанров.
- Удаление фильма из истории выполняет ровно один выход назад (не «прыгает» на карточку).
- Плеер: защита от NPE `window.insetsController` при пересоздании активити (поворот/смена размера).

## Тесты

- Unit: **346** (сеть/Ethernet, VPN, статус сети, меню качества, подписи источников, MIME внешнего
  плеера, разделение жанров, encode/decode фильтров, исход удаления истории).
- Instrumentation на мобильном эмуляторе: `playerview` 20, `player` 3, `tv.player` 11, `tv` 13 —
  OK. Новый `MultiRenditionQualityTest` (фикстура `/multirend/master.m3u8`, 180p/360p/720p) проверяет
  выбор качества и переход между сериями.

## Проверено вживую

- CPU-эмуляторы Pixel 5 (API 30) и Television 1080p, `-gpu off`.
- Внешний плеер: официальный VLC 3.7.1, запуск через chooser, возврат без автозапуска (MediaSession
  `PAUSED`).
- Компоновка плеера на 720×1280 и 480×800 — шесть кнопок помещаются.

## Не проверено

- Физический Ethernet на приставке (нужен кабель).
- Источник с обязательным `Referer` во внешнем плеере — по коду кнопка скрыта, живого примера нет.
- Ручной выбор жанров на TV через D-pad (headless-эмулятор не дал воспроизвести навигацию).
