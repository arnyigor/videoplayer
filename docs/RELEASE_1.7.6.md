# Релиз 1.7.6

Версия: **1.7.6** (`versionCode 1706`). Изменения в `version.properties`; подпись берётся из локального
`signing.properties`, публикация — GitHub-workflow по тегу `v1.7.6`.

## Что вошло

### Устойчивость к смене домена сайта

Сайт периодически меняет зеркала (у пользователей в этот момент не грузятся постеры и ничего не
воспроизводится). Резолв адреса переработан:

- **цепочка кандидатов** вместо одной ссылки: стабильная входная страница → адрес из сборки →
  файл `base_link.txt` на GitHub-релизе (обновляется без выпуска приложения) → ранее сохранённый адрес;
- каждый найденный адрес **проверяется живым запросом** `/films/` (2xx), мёртвое зеркало не
  подменяет рабочее;
- если недоступны все — приложение больше **не молчит**: диалог «Сайт недоступен» с кнопками
  «Повторить» (перепроверяет зеркала) и «Открыть сохранённое».

### Заставка (сплэш)

Полностью переделана: раньше показывались две заставки подряд (статичная системная иконка, затем
наша сцена), а на холодном старте первые секунды был пустой фон.

- системная заставка отключена (на Android 12+ — погашена прозрачной иконкой);
- окно сразу рисуется с градиентом и логотипом, сцена — по центру экрана;
- логотип входит масштабом с лёгким поворотом, вокруг расходятся **сонар-волны**;
- по названию бежит блик (градиент на самих буквах), под ним пульсируют три точки;
- при переходе в приложение сцена «раскрывается», а не гаснет;
- инициализация зависимостей перенесена на после первого кадра — анимация начинается сразу.

## Тесты и проверки

- Unit: **346**, падений нет.
- Проверено на CPU-эмуляторах (Pixel 5 API 30, Television 1080p, `-gpu off`) и на OnePlus 6T:
  старт, резолв зеркала, отсутствие второй заставки, геометрия сцены, поведение при недоступном сайте.

## Не проверено

- Физический Ethernet на ТВ-приставке.
- Живой источник с обязательным `Referer` во внешнем плеере.
- Ручной выбор жанров на ТВ через D-pad.
