# Релиз 1.7.7

Версия: **1.7.7** (`versionCode 1707`). Публикация подписанных APK и AAB — workflow по тегу `v1.7.7`.

## Изменения

- **Поиск по каталогу:** регистр, е/ё, дефисы и другие разделители больше не мешают совпадению. Названия, актёры и режиссёры ищутся по всем введённым словам; жанры и страны используют нормализованные значения. Подход применяется также в истории и избранном.
- **Поиск на сайте:** подгружаются следующие страницы сериалов, повтор последней страницы останавливает пагинацию, в том числе при совпадении с локальными карточками. Результаты без совпадения названия вынесены отдельно; поиск по актёрам и режиссёрам не получает ошибочную отметку «не совпадают».
- **Заставка:** статичный крупный логотип на градиенте вместо долгой анимации и принудительного ожидания. Резервный файл адреса сайта загружается только после отказа основных адресов.
- **Переходы:** короткое плавное затухание при выходе со сплеша, между мобильными экранами и при возврате назад.
- **Настройки:** добавлены заголовок и кнопка «Назад», исправлены отступы, нижняя навигация скрыта. Debug-раздел перенесён вниз и свёрнут; в release его нет. Исправлены единицы усиления звука (мБ/дБ вместо процентов) и проверка ввода. Ключи настроек сохранены.

## Обновление

Поисковые поля существующего каталога заполняются автоматически при миграции БД до версии 10. Удалять приложение или повторно загружать каталог не требуется. Первый запуск после обновления может занять больше времени.

Новые источники видео не добавлялись; доступность поиска на сайте и воспроизведения по-прежнему зависит от Anwap.

## Проверки

- Локально: **380 unit-тестов**, без падений; сборки debug и release с R8; lint без ошибок (предупреждения остаются).
- На OnePlus с Android 11: **7 миграционных тестов** для БД версий 3–9 → 10; проверен обновлённый каталог из **47 921 записи** и нормализация поисковых полей.
- Обновлённый экран настроек открыт и проверен на телефоне.
- Полный визуальный прогон переходов, Android 12+ и TV, а также изменение громкости и запуск обновления каталога через новые настройки не проверялись.
