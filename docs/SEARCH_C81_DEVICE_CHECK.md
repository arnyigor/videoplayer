# c-81: живая проверка поиска на CPU-эмуляторе

Приложение `perfdebug` (Media3), фикстурная база 1000 тайтлов загружена, `adb reverse 8765`.

## Что проверено

Запрос `matrix` (латиницей — иначе `adb input text` не умеет кириллицу), кнопка «Поиск»:

- локальная выдача находится: три строки «Матрица» / «Матрица: Перезагрузка» / «Матрица»
  с бейджем **«В каталоге»**;
- заголовков секций нет — и это правильно по правилу S-013: заголовки добавляются, только когда
  в списке есть **оба** источника, а внешняя выдача здесь пустая;
- пустого экрана/ошибки нет, поле сохраняет запрос.

Скриншот: `build/perf/c81/search-local.png`, дамп: `build/perf/c81/search-matrix3.xml`.

## Что НЕ проверено и почему

- **Секции «В каталоге (фильтры применены)» / «На сайте (фильтры недоступны)» на устройстве**
  не показаны: внешний источник в этой сборке смотрит на реальный `BASE_URL` из prefs
  (фикстуры подменяют только БД), поэтому сайт ничего не вернул. Логика секций проверена
  юнит-тестами `SearchListSectionsTest` (4/4), но не глазами на экране.
- **Позиция прокрутки при Back** не проверена: локальная выдача — три строки, список не
  прокручивается, проверять нечего.

Оба пункта — ограничение тестовых данных (нет одновременной непустой выдачи обоих источников),
а не дефект экрана.
