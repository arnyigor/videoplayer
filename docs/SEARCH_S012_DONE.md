## Оговорки, которые нужно помнить

- Раздельные индикаторы — это текст статуса, а не два отдельных прогресс-бара; общий
  `pbSiteSearch` тоже остался.
- Пустое состояние и тексты ошибок по источникам проверены кодом и юнит-тестами, но не
  отдельным кликом на устройстве для каждого из четырёх вариантов.
- Смена источника на «только сайт» с активными фильтрами гасит кнопку фильтров
  (`docs/SEARCH_S013_SITE_ONLY.md`), но сохранённые фильтры не сбрасываются — при возврате на
  «Везде» они снова применяются. Это осознанное поведение, не баг, но в плане не оговорено.
