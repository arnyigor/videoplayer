# S-013 + S-012: подтверждено на устройстве

## Что исправлено в тестовых данных

`scripts/perf_fixtures.py`: ответ сайта на поиск теперь содержит **второй, «сайтовый» тайтл**
«Матрица: Воскрешение / The Matrix Resurrections» (2021), которого нет в фикстурной базе.
Без этого внешняя выдача сливалась с локальной и секции не появлялись — проверить S-013 на
экране было нечем.

## Проверка на CPU-эмуляторе (perfdebug, фикстуры)

Запрос `matrix`, режим «Везде». Дамп экрана (`build/perf/c81/search-both-top.xml`) показывает
оба заголовка и правильное распределение:

```
В каталоге (фильтры применены)   ← 3 локальных «Матрицы» с бейджем «В каталоге»
На сайте (фильтры недоступны)    ← «Матрица: Воскрешение» (результат сайта)
```

Скриншот: `build/perf/c81/search-sections.png`.

## Позиция прокрутки при Back (S-012)

1. Прокрутил список (`scroll-before.xml`), открыл «Матрица: Перезагрузка» → экран деталей.
2. Back → экран поиска.
3. Видимые элементы и их координаты **совпали полностью** (`scroll-after.xml`,
   `scroll-result.json`: `preserved: true`), запрос `matrix` сохранился.

## Итог

- S-012: критерий «возврат в ту же вкладку/запрос и предыдущую позицию без обновления» —
  подтверждён на устройстве.
- S-013: секции «В каталоге (фильтры применены)» / «На сайте (фильтры недоступны)» — видны
  на устройстве, не только в юнит-тестах.

Осталось непроверенным: поведение при смене источника на «только сайт» с активными фильтрами
(кнопка выключена — проверено только кодом и юнит-тестом доступности).
