# S-013: фильтры применимы только к каталогу — секции и отключение

## Что было

Фильтры поиска работают по локальной базе. В режиме «Везде» список смешивал каталог и сайт без
каких-либо пометок, поэтому выглядел как одинаково отфильтрованный: часть строк (сайт)
фильтры вообще не проходила. Была только одна мелкая подпись `tvFiltersNotice`, а в режиме
«только сайт» кнопка фильтров оставалась активной и молча ничего не давала.

## Что сделано

1. `SearchListSections` — чистая логика списка:
   - в режиме «Везде» при наличии обоих источников выдача делится на секции
     **«В каталоге (фильтры применены)»** и **«На сайте (фильтры недоступны)»**;
   - для одного источника заголовки не добавляются (не шумят);
   - `areFiltersAvailable(source)` = ложь только для режима «На сайте».
2. `SiteSearchAdapter` переведён на `ListAdapter<SearchListItem, …>` с двумя типами ячеек
   (карточка и заголовок секции), `i_search_section_header.xml` — сама плашка заголовка.
3. Экран: список собирается через `SearchListSections.build(...)`; в режиме «только сайт»
   кнопка фильтров **выключена** и подписана «Фильтры каталога недоступны в режиме «На сайте»».
