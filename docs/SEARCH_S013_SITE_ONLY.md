# S-013: режим «только сайт» — фильтры выключены (проверка на устройстве)

Запрос `matrix`, переключение источника на **«На сайте»** (CPU-эмулятор, perfdebug + фикстуры).

Дамп (`build/perf/c82/site-only.xml`):

| Элемент | Состояние |
|---|---|
| Кнопка фильтров | текст «Фильтры каталога недоступны в режиме «На сайте»», `enabled = false` |
| Список | только сайтовые результаты («Матрица», «Матрица: Воскрешение»), локальных строк и бейджей «В каталоге» нет |
| Поле запроса | `matrix` сохранён |

Скриншот: `build/perf/c82/site-only.png`.

То есть фильтры не «молча игнорируются»: кнопка выключена и объясняет причину — как требует S-013.
