# S-020: строка результатов поиска стала компактной

## Что сделано

Строка результата (`i_site_search.xml` + `SiteSearchAdapter`) раньше была высокой: миниатюра
**108dp**, название до 2 строк, строка метаданных, бейдж «В каталоге» и описание до 2 строк —
до пяти текстовых строк на элемент.

Теперь:

| Параметр | Было | Стало |
|---|---|---|
| Миниатюра | 108dp | **72dp** |
| Название | до 2 строк | **1 строка** |
| Метаданные | 1 строка | 1 строка (`год • тип • рейтинг • оригинальное`) |
| Описание в списке | до 2 строк | **убрано** (описание остаётся на экране деталей) |

Проверено на устройстве (запрос `matrix`, режим «Везде»): строки идут `Матрица 2005 • Фильм •
5,5`, `Матрица: Перезагрузка 2003 …`, `Матрица 1999 …`, ниже секция «На сайте (фильтры
недоступны)» → `Матрица: Воскрешение 2021 • Фильм • 5,7 • The Matrix Resurrections`
(`build/perf/c100/search-compact.xml`, скриншот `search-compact.png`).

## Что уже соответствовало плану

- **Активный источник виден**: переключатель «Везде / В каталоге / На сайте».
- **Число фильтров видно**: кнопка «Фильтры» / «Фильтры: N», в режиме «только сайт» —
  «Фильтры каталога недоступны» и кнопка выключена (c-82).
- **Ошибки сайта и базы различаются**: отдельные тексты и строка статуса (c-75/78).
- **IME search**: `android:imeOptions="actionSearch"` и обработчик submit.
- **Второго экранированного поиска на главной нет**: inline SearchView удалён (c-97), лупа
  ведёт на этот экран.

## Отступление от плана

Поле ввода занимает **не всю ширину**: справа остаётся кнопка «Поиск». Убирать её — значит
менять привычный способ запуска и ломать существующие UI-тесты, которые нажимают
`btnSiteSearch`; в этом цикле не делал. Живой поиск по вводу при этом тоже работает.
