# S-016: как сортировка устроена сейчас (сверка, не правка)

Шаг S-016 в плане — это «сейчас»: он описывает состояние, которое нужно привести к единому виду
в S-017. Ниже — фактическое состояние, сверенное по коду и на устройстве.

## Каталог «Фильмы / Сериалы» (экраны 02/03)

- Встроенный каталог главной (`HomeFragment.kt:899`, `showTitle = false`) показывает **только
  иконку** сортировки: `MobileCatalogScreen.CatalogSortSelector` — `IconButton` с `ic_sort`,
  текст режима убран по прямой просьбе оператора (было «Сортировка: Новинки» текстовой ссылкой).
- Отдельный экран каталога (`MobileCatalogFragment`, `showTitle = true`) показывает тот же
  `IconButton` — единый компонент, второй реализации нет.
- Доступность сохранена: у кнопки `contentDescription = "Сортировка: <режим>"`.
  Проверено на устройстве: узел с описанием «Сортировка: Новинки» в правом верхнем углу
  (`build/perf/c88/catalog.xml`, скриншот `build/perf/c88/catalog-sort-icon.png`).

Отличие от текста плана («правая текстовая ссылка `Сортировка: Новинки`») — намеренное:
иконку попросил владелец, чтобы строка жанров помещалась целиком.

## Overflow «Ещё» (экран 06)

Пункт **«Настройки сортировки»** по-прежнему есть: меню `home_menu.xml` →
`action_order_settings` → `HomeFragment.kt:1090`. Проверено на устройстве: в открытом
overflow видны «Поиск на сайте», «Настройки сортировки», «Открыть ссылку», «Импорт ссылки»,
«Обновить локальные данные» (`build/perf/c88/overflow.xml`, `overflow.png`).

Тот же пункт дублируется в истории и избранном (`HistoryFragment.kt:174`,
`FavoritesFragment.kt:190`) — три входа к одним и тем же настройкам.

## Поиск

Сортировка есть отдельной иконкой и своим bottom sheet (`SearchFiltersSheet`), как и написано
в плане: `btnSearchFilters` + `apply` внутри шита.

## Вывод для S-017

Расхождение с планом одно и важное: **сортировка каталога уже иконочная**, а не текстовая
ссылка. Целевое состояние S-017 («одна видимая кнопка с иконкой, общий `CatalogSortSheet`,
убрать пункт из overflow») частично достигнуто по первому пункту; остаётся общий шит вместо
текущего `DropdownMenu` и перенос/удаление пункта overflow.
