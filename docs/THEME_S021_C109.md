# S-021 — цикл c-109 (revision 60)

План перечитан до действий. TalkBack по решению оператора отложен в S-078 на финальную ручную приёмку; отсутствие APK больше не блокирует S-021. Контроллерный файл в этом цикле не изменялся.

## Изменения

- В legacy-главной три кнопки «Все / Фильмы / Сериалы» имели фиксированную высоту 40dp. Предыдущая проверка только Compose MinTouchTarget не покрывала их. Заменено на wrap_content + minHeight=48dp: зона нажатия не меньше 48dp, текст может увеличивать высоту. Это выполнение существующего критерия S-021, не отдельная новая находка.
- Лупа toolbar использовала платформенный android:drawable/ic_menu_search, отличный от нижней навигации. Теперь обе используют проектный вектор ic_nav_search (24dp). Остальные существующие изменения home_menu сохранены.

## Проверка

- На AVD Android 11: физическая ширина 1080px, density 440dpi, то есть 392.73dp (округлённо 393dp). Размер и плотность не переопределялись.
- perfdebug сначала отсутствовал; собран актуальный APK и успешно установлен. После правок повторная сборка и установка успешны (exit=0): build/perf/c109/build-after.log, install-after.log.
- UIAutomator после установки: все три переключателя имеют высоту 132px / 2.75 = 48dp. Машинные проверки прошли, измерения: build/perf/c109/touch-targets.json; дамп: home393-after.xml.
- Главная и поиск при 393dp просмотрены; шапка, источники и нижняя навигация без видимого обрезания. Поиск открыт нажатием новой лупы.
- При открытии клавиатуры поле/кнопка поиска, источники и нижние вкладки остаются видимыми: build/perf/c109/search393-ime.png. Это проверка текущего adjustResize, не доказательство полноценной поддержки edge-to-edge.
- BottomNavigationView: один itemIconSize=24dp; iconTint и textColor используют общий nav_item_color_state (акцент для checked, secondary иначе). Все четыре вектора имеют viewport 24x24. Визуальный вес заполненных home/favorite и линейных search/history не идентичен; единая оптическая толщина ещё не подтверждена.
- A11yLabelCoverageTest: 1 тест, 0 ошибок, 0 пропусков; Gradle exit=0. Лог: build/perf/c109/a11y-labels.log. Проверка меток не равна проверке TalkBack.
- git diff --check затронутых ресурсов: ошибок нет (предупреждение Git о нормализации LF/CRLF).

## Остаток S-021

- В MainActivity не обнаружена явная настройка edge-to-edge/insets. Скриншоты подтверждают только отсутствие перекрытий системными панелями в текущем режиме Android 11. Полноценный edge-to-edge не подтверждён.
- Визуальная проверка остальных View-диалогов после изменений MyDialogStyle остаётся открытой (F-041).
- Единый визуальный вес иконок, а также достаточность зон нажатия всех экранов (не только трёх проверенных переключателей) требуют дальнейшей проверки.

S-021 не закрыт. Новые блокеры среды не обнаружены.
