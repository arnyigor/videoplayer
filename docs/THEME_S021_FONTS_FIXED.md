# S-021 / F-037: крупный шрифт — исправлено

## Причина и правка

При `font_scale 2.0` переключатель источника обрезался: три кнопки в одной строке вместе с
кнопкой «Фильтры» не помещались, а `HorizontalScrollView` не прокручивался (свайп не сдвигал
содержимое — проверено сравнением хешей скриншотов).

Что сделано:

1. **Короткие подписи источников**: «В каталоге» → «Каталог», «На сайте» → «Сайт»
   (строки `search_source_local` / `search_source_remote`).
2. **Раскладка**: группа источников теперь занимает **всю ширину своей строки**, а кнопка
   «Фильтры» переехала строкой ниже (родитель стал `orientation="vertical"`).

## Проверка

| Режим | Результат |
|---|---|
| `font_scale 2.0` | «Везде», «Каталог», «Сайт» читаются **полностью**; «Фильтры» отдельной строкой (`build/perf/c103/font20-v2.png`) |
| `font_scale 1.0` | то же размещение, ничего не сломалось (`font10-v2.png`) |
| Регресс | юнит-тесты BUILD SUCCESSFUL; `SearchQueryIntegrationTest` — 2 теста, 0 падений, 1 пропуск (пустая БД после переустановки) |

`font_scale` возвращён в 1.0.

## Чему научил этот цикл

Первые попытки «не работали», потому что **сборка падала** на дублирующем `android:minWidth`,
а `adb install` молча ставил старый APK. Теперь сборка проверяется по коду выхода
(`echo exit=$?`), а не по отсутствию строк `e:` в логе.

## Остаток по S-021

Не проверены: TalkBack, landscape, ширины 320/360/393/412 dp, планшет 600dp+, единый визуальный
вес иконок, и приведение View-`AlertDialog` (диалог ошибки плеера) к Compose-токенам.
