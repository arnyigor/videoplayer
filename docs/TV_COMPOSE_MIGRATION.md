Проверено сборкой: `:app:assembleDebug` — **BUILD SUCCESSFUL**, APK 25.6 MB (13:17).
Проверено на эмуляторе `Television_1080p` (1920×1080, 320 dpi): пробный экран

## 3. Целевой стек (по спецификации §12) и разрывы с текущим кодом

| Слой | Цель | Сейчас | Разрыв |
|---|---|---|---|
| UI | `androidx.tv:tv-material` + Compose Foundation | Leanback (Browse/Details/Search + презентеры) | 4 экрана переписать |
| Навигация | Navigation Compose | Navigation Component + SafeArgs (XML) | переписать граф TV-части |
| Плеер | Media3 ExoPlayer | ExoPlayer 2.19.1 + `PlayerView` | миграция API плеера (отдельная фаза) |
| Изображения | Coil | Glide 4.16 | Coil 3.x в KMP; для Android достаточно Coil 2.x, либо `glide-compose` |
| Состояние | ViewModel + StateFlow | уже так | переиспользуем VM |
| DI | Koin | уже Koin | без изменений |

Важно: **переиспользуем существующие ViewModel и Paging** — переписывается только слой представления.
`TvHomeViewModel`, `TvDetailsViewModel`, `PlayerViewModel`, `SiteSearchViewModel` остаются.

## 5. Риски и как их снимать

| Риск | Митигция |
|---|---|
| Потеря фокуса/скролла при возврате | `focusRestorer()`, устойчивые `key`, явное сохранение `focusedTitleId` + индексов (спека §9.1); проверять сценарии HOME-FOCUS-01/SERIES-FOCUS-02 |
| Paging + Compose | `paging-compose` 3.3.x (совместим с paging 3.1? — проверить), иначе обёртка над `PagingDataAdapter` |
| Glide в Compose | либо `coil-compose` (проще), либо `glide-compose`; следить за размером картинок под 4K |
| `tv-material` 1.0.1 — ранний API (часть компонентов experimental) | свои обёртки в `core/designsystem`, минимум прямых импортов по экранам |
| Смешение Leanback и Compose в одном NavGraph | один экран за раз, `ComposeView` во фрагменте; навигация остаётся XML до Фазы 5 |
| Media3 | не блокирует TV-UI; делать после Фаз 1–2 |
| R8/размер | проверить release-сборку после Фазы 1, до полного переезда |
